Мини-нейросеть: демонстрационная классификация

Небольшая нейросетевая модель получает два признака сигнала и выбирает вероятный класс. Это прототип с вручную заданными весами, не обученная на датасете модель.

Включи микрофон, чтобы анализировать звук.
Обнаружение событий: пока событий нет. Включи микрофон и хлопни в ладоши.

Настоящая предобученная нейросеть YAMNet

YAMNet — настоящая предобученная нейросеть для классификации 521 класса звуков. Результаты отображаются по-русски там, где доступен перевод. Модель и вычислительный модуль загружаются из интернета при запуске. Подключи микрофон и нажми кнопку ниже.

Модель ещё не загружена.
Здесь появятся наиболее вероятные классы звука.
Распознавание мотора: включи YAMNet и воспроизведи звук работающего двигателя.
